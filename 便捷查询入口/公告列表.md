# 公告列表（MCP 工具 `report_announcement_list`）

> `report_announcement_list` 是只读公告列表工具。本文参数与 2026-08-05 公共服务 `tools/list` 返回的 `inputSchema` 对齐；实时约束仍以调用时的 `tools/list` 为准。成功结果统一返回 `structuredContent.metadata` + `structuredContent.data`，`content[0].text` 是同值的序列化 JSON。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|---|---|---|---|
| date | string | Y | 公告日期 `YYYYMMDD`，如 `20260624` |
| sec_code | string | N | 按证券代码过滤；不传时返回当天全部证券公告 |
| page | integer | N | 页码，默认 1，最小 1 |
| page_size | integer | N | 每页条数，默认 50，范围 1～200 |

`announcement_id` 可继续传给 [`report_announcement_summary`](../大模型语料/公告摘要.md) 查询单条公告摘要。未在 `inputSchema` 中声明的字段会被拒绝。

## data 业务字段

| 名称 | 描述 |
|---|---|
| announcement_id | 公告 ID |
| sec_code | 证券代码 |
| sec_name | 证券名称 |
| announcement_title | 公告标题 |
| announcement_time | 公告时间 |
| status | 公告处理状态；可能为 `pending`、`failed` 或 `summarized` |

未命中的可选字段可能为 `null`。

## 调用示例

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"report_announcement_list","arguments":{"date":"20260624","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp==2.0.0`）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "report_announcement_list",
                {"date": "20260624", "page": 1, "page_size": 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
