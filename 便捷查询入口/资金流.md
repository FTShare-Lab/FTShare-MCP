# 资金流（MCP 工具 `capital_flow`）

> `capital_flow` 是只读资金流聚合工具。本文参数与 2026-08-05 公共服务 `tools/list` 返回的 `inputSchema` 对齐；实时约束仍以调用时的 `tools/list` 为准。成功结果统一返回 `structuredContent.metadata` + `structuredContent.data`，`content[0].text` 是同值的序列化 JSON。

## 支持口径

| `type` | 用途 | 关键参数 |
|---|---|---|
| `stock`（默认） | 个股主力资金，包含超大单、大单、中单和小单净流入 | 可选 `symbol`、`date`、`time`、分页参数 |
| `eastmoney_stock` | 东方财富个股资金流 | 分页参数 |
| `eastmoney_market` | 东方财富大盘资金流 | 分页参数 |
| `eastmoney_sector` | 东方财富板块资金流 | 分页参数 |
| `northbound` | 北向资金聚合 | `date` 必填 |
| `southbound` | 南向资金聚合 | `date` 必填 |

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|---|---|---|---|
| type | enum | N | 默认 `stock`；可选值见上表 |
| date | string | 按 type | 日期 `YYYYMMDD`；`northbound` / `southbound` 必填，其余口径可选 |
| time | string | N | 盘中切片时刻 `HHMM`，如 `1530`；仅 `stock` 使用 |
| symbol | string | N | 按标的过滤，仅 `stock` 使用；如 `000001.SZ`，也接受 `000001.XSHE` |
| page | integer | N | 页码，默认 1，最小 1 |
| page_size | integer | N | 每页条数，默认 50，范围 1～500 |

`northbound` 和 `southbound` 不分页；其他口径使用 `metadata.pagination` 返回分页信息。未在 `inputSchema` 中声明的字段会被拒绝。

## 输出字段

不同 `type` 的业务字段不同，以下字段来自已部署服务的实际成功响应：

| `type` | `data` 主要字段 |
|---|---|
| `stock` | `symbol`、`ts_nanos`、`net_inflow_extra_large`、`net_inflow_large`、`net_inflow_medium`、`net_inflow_small` |
| `eastmoney_stock` | `code`、`name`、`trade_date`、`close_price`、`change_pct`、各档净流入及占比 |
| `eastmoney_market` | `trade_date`、上证/深证收盘点位与涨跌幅、各档净流入及占比 |
| `eastmoney_sector` | `sector_code`、`sector_name`、`sector_type`、`trade_date`、各档净流入及占比 |
| `northbound` | `date`、`currency`、`total_amount`、`channels.SH`、`channels.SZ` |
| `southbound` | `date`、`currency`、`total`、`channels.SH_HK`、`channels.SZ_HK` |

## 调用示例

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"capital_flow","arguments":{"type":"stock","date":"20260624","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp==2.0.0`）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "capital_flow",
                {"type": "stock", "date": "20260624", "page": 1, "page_size": 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```

其他口径只需替换 `arguments`。已部署服务的回归参数为：

```json
{"type":"eastmoney_stock","page":1,"page_size":2}
{"type":"eastmoney_market","page":1,"page_size":2}
{"type":"eastmoney_sector","page":1,"page_size":2}
{"type":"northbound","date":"20260624"}
{"type":"southbound","date":"20260624"}
```
