# 资金流（MCP 工具 `capital_flow`）

> **MCP 工具**：`capital_flow`（category: `便捷查询入口`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询个股主力资金、东方财富个股、大盘与板块资金流，以及北向、南向资金六种口径；个股主力资金包含超大、大、中、小单净流入，东方财富口径还包含主力及各档净流入占比，北向和南向资金按渠道拆分，查询北向或南向资金时日期必填。
- 数据范围：A 股个股、东财个股/大盘/板块、北向/南向资金
- 单次限量：`page_size` 上限 500，默认 50；northbound/southbound 无分页
- 提示：
  - `type` 默认 `stock`，其余口径需显式传入。
  - `northbound`/`southbound` 必填 `date`（YYYYMMDD）。
  - `stock` 口径可选传 `date`（YYYYMMDD）和 `time`（HHMM 盘中切片）及 `symbol`（标的过滤）。
  - 不同 `type` 返回的 data 字段集不同（见下文输出参数）。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| type | string | N | 数据口径，默认 `stock`；可选 `stock`/`eastmoney_stock`/`eastmoney_market`/`eastmoney_sector`/`northbound`/`southbound` |
| date | string | 条件 | 日期 YYYYMMDD；`northbound`/`southbound` 必填，其余口径可选 |
| time | string | N | 盘中切片时刻 HHMM（如 `1530`），仅 `stock` 口径 |
| symbol | string | N | 按标的过滤，仅 `stock` 口径；Wind 风格 `000001.SZ`（也接受 `000001.XSHE` 格式） |
| page | int | N | 页码，默认 1 |
| page_size | int | N | 每页条数，默认 50，上限 500 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| net_inflow_extra_large | string | Y | 超大单净流入 |
| net_inflow_large | string | Y | 大单净流入 |
| net_inflow_medium | string | Y | 中单净流入 |
| net_inflow_small | string | Y | 小单净流入 |
| symbol | string | Y | 证券代码 |
| ts_nanos | int64 | Y | 时间戳（纳秒） |

> 其他口径返回字段不同：
> - `eastmoney_stock`：`code`/`name`/`trade_date`/`close_price`/`change_pct`/`main_net`/`main_pct`/`super_large_net`/`super_large_pct`/`large_net`/`large_pct`/`medium_net`/`medium_pct`/`small_net`/`small_pct`/`market`
> - `eastmoney_market`：`name`/`trade_date`/`sh_close`/`sh_change_pct`/`sz_close`/`sz_change_pct`/`main_net`/`main_pct`/`xlarge_net`/`xlarge_pct`/`large_net`/`large_pct`/`mid_net`/`mid_pct`/`small_net`/`small_pct`
> - `eastmoney_sector`：`sector_code`/`sector_name`/`sector_type`/`trade_date`/`main_net`/`main_pct`/`super_large_net`/`super_large_pct`/`large_net`/`large_pct`/`medium_net`/`medium_pct`/`small_net`/`small_pct`
> - `northbound`：`date`/`currency`/`total_amount`/`channels`（含 SH/SZ 拆分）
> - `southbound`：`date`/`currency`/`total`/`channels`（含 SH_HK/SZ_HK 拆分）

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"capital_flow","arguments":{"type":"stock","date":"20260624","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'capital_flow',
                {'type': 'stock', 'date': '20260624', 'page': 1, 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
