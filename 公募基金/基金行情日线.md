# 基金行情日线（MCP 工具 `ft_get_fund_daily`）

> **MCP 工具**：`ft_get_fund_daily`（category: `公募基金`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：按场内交易代码查询 ETF、LOF、分级基金、REIT 等场内基金的不复权日线行情；`trade_date` 单日条件与 `start_date`/`end_date` 区间条件互斥。数据包括基金代码与名称、交易日期、前收盘价、开高低收、均价、涨跌额与涨跌幅、换手率、成交量、成交额、振幅及折溢价与折溢价率。
- 数据范围：按交易日查询
- 单次限量：默认 `page=1`/`page_size=50`；上限 200
- 提示：
  - `fund_code` 必填，必须为六位数字并带 `.SZ` 或 `.SH` 后缀，例如 `159562.SZ`、`510880.SH`。裸码及 `.OF` 代码会返回参数错误。
  - 后缀大小写不敏感，统一按大写处理；文档示例统一使用大写。
  - `trade_date` 与 `start_date`+`end_date` 互斥；区间查需 `start_date` 与 `end_date` 同时传。
  - 必须提供 `trade_date`，或同时提供 `start_date` 与 `end_date`；日期格式为有效的 `YYYYMMDD`。
  - 行情数据与基金基础信息按场内交易代码关联。
  - 本接口仅返回不复权日线，不提供前复权、后复权以及周/月/年线。
  - 部分标的近期行情可能为空（数据源滞后）。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| fund_code | string | Y | 场内交易代码：六位数字并带 `.SZ` 或 `.SH` 后缀 |
| trade_date | string | N | 交易日期 YYYYMMDD（与 start/end 互斥） |
| start_date | string | N | 起始日期 YYYYMMDD（需与 end_date 同传） |
| end_date | string | N | 结束日期 YYYYMMDD |
| page | int | N | 页码，默认 1 |
| page_size | int | N | 每页条数，默认 50，上限 200 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

|------|------|---------|------|

| average_price | string | Y | 均价 |
| change_ratio | string | Y | 涨跌幅，百分比原值 |
| close_price | string | Y | 收盘价 |
| discount_premium | string | Y | 折溢价 |
| discount_premium_ratio | string | Y | 折溢价率，百分比原值 |
| fund_code | string | Y | 基金代码，不带交易所后缀 |
| fund_name | string | Y | 基金名称 |
| high_price | string | Y | 最高价 |
| low_price | string | Y | 最低价 |
| open_price | string | Y | 开盘价 |
| previous_close | string | Y | 前收盘价 |
| price_change | string | Y | 涨跌额 |
| trade_code | string | Y | 场内交易代码，带 `.SZ` 或 `.SH` 后缀 |

| turnover | string | Y | 成交额，元 |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_get_fund_daily","arguments":{"fund_code":"510300.SH","trade_date":"20260724","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_get_fund_daily',
                {'fund_code': '510300.SH', 'trade_date': '20260724', 'page': 1, 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
