# 公告列表（MCP 工具 `ft_stock_announcements`）

> **MCP 工具**：`ft_stock_announcements`（category: `大模型语料`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询 A 股公告列表。支持按 `stock_code` 查询单票历史公告，或按 `start_date` 查询指定单日的全市场公告。提示：必须提供 `stock_code` 或 `start_date` 之一，否则报错；`type` 当前只支持 `stock`；`start_date` 格式 YYYYMMDD，仅取该日公告。
- 数据范围：以服务端返回为准
- 单次限量：分页返回，`page` / `page_size` 必填；日期模式仅支持单日
- 提示：
  - 二选一：必须提供 `stock_code`（按标的查）或 `start_date`（按日期范围查），否则报错。
  - `type` 当前只支持 `"stock"`。
  - MCP 日期模式只公开 `start_date`，格式 `YYYYMMDD`，用于查询指定单日。
  - 公告正文文件下载请用 `/api/v1/market/data/announcements/stock-announcements/{url_hash}`（另见独立接口）。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| stock_code | string | N | 证券代码（按标的查询时必填） |
| start_date | string | N | 公告日期 YYYYMMDD（按日期查询时必填） |
| type | string | Y | 查询类型，当前只支持 `stock` |
| page | int | Y | 页码 |
| page_size | int | Y | 每页条数 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项；元素字段见下方 |

### data 业务字段

AnnouncementItem：

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| stock_code | string | Y | 证券代码 |
| stock_name | string | Y | 证券名称 |
| announcement_id | string | Y | 公告 id |
| announcement_title | string | Y | 公告标题 |
| announcement_time | string | Y | 公告时间，格式 YYYY-MM-DD HH:MM:SS |
| column_type | string | Y | 栏目类型 |
| url_hash | string | Y | 公告文件 URL 哈希，用于下载正文文件 |

## 调用方法（MCP）

> MCP 工具名 `ft_stock_announcements`。MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_stock_announcements","arguments":{"type":"stock","stock_code":"600519.SH","page":1,"page_size":3}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_stock_announcements',
                {'type': 'stock', 'stock_code': '600519.SH', 'page': 1, 'page_size': 3},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
