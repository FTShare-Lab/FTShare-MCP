# 研报分类（MCP 工具 `ft_type_reports`）

> **MCP 工具**：`ft_type_reports`（category: `大模型语料`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：按研报类型和日期范围查询研报基础信息，支持宏观、行业、券商晨报、策略和新股研报；研报类型与开始日期必填，未指定结束日期时查询开始日期当天，日期范围不超过 3 天。
- 数据范围：按报告期查询
- 单次限量：分页返回，`page` / `page_size` 必填；`start_date` / `end_date` 区间跨度不能超过 3 天
- 提示：
  - `rept_type` 必填，取值仅限 5 类：`MacroReport` / `IndustryReport` / `BrokerMorningReport` / `StrategyReport` / `NewStockReport`。
  - `start_date` 必填；`end_date` 不填时默认等于 `start_date`（查单日）。
  - `start_date` / `end_date` 格式 `YYYYMMDD`，区间不能超过 3 天。
  - 出参结构同「研报列表」`StockReportItem`，`rating_change` 为中文。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| rept_type | string | Y | 研报类型：MacroReport / IndustryReport / BrokerMorningReport / StrategyReport / NewStockReport |
| start_date | string | Y | 开始日期 YYYYMMDD |
| end_date | string | N | 结束日期 YYYYMMDD，不填默认与 `start_date` 相同 |
| page | int | Y | 页码 |
| page_size | int | Y | 每页条数 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| last_report_rating_name | string | Y | 上次评级名称 |
| last_report_rating_value | string | Y | 上次评级等级 |
| rating_change | string | Y | 评级变动中文：维持 / 上调 / 下调 / 首次覆盖 |
| rating_researcher | string | Y | 研究员 |
| report_Institution | string | Y | 研究机构（序列化名 `report_Institution`） |
| report_id | string | Y | 研报 id |
| report_rating_name | string | Y | 本次评级名称 |
| report_rating_value | string | Y | 本次评级等级 |
| report_time | string | Y | 发布时间 YYYYMMDD |
| report_title | string | Y | 研报标题 |
| stock_code | string | Y | 股票代码 |
| stock_name | string | Y | 股票名称 |
| url_hash | string | Y | 研报文件 URL 哈希 |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_type_reports","arguments":{"rept_type":"MacroReport","start_date":"20260624","page":1,"page_size":2,"end_date":"20260624"}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_type_reports',
                {'rept_type': 'MacroReport', 'start_date': '20260624', 'page': 1, 'page_size': 2, 'end_date': '20260624'},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
