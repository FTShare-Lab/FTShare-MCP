# 申万行业日度指标（MCP 工具 `ft_sw_industry_daily_metrics`）

> **MCP 工具**：`ft_sw_industry_daily_metrics`（category: `指数专题/申万行业`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询单个申万行业的日频估值、资金和量价指标时间序列，含 PE、PB、股息率、换手率、总市值、收盘价、破净比例、指数收盘、成交额及拥挤度等字段。`level` 可选，不传时按 `industry_code` 自动匹配层级。
- 数据范围：2021-05-31 至今（跨 801010.SI/801030.SI/801080.SI 等多行业探测，最早均为 2021-05-31）
- 单次限量：无 3 天跨度限制，由 page/page_size 分页
- 提示：
  - `level` 可选，取值 1/2/3；`start_date`/`end_date`/`industry_code` 必填。
  - 日期格式 **YYYYMMDD**；`industry_code` 必须带 `.SI` 后缀（如 801010.SI），不带会查不到数据。
  - 返回 `{code,message,data:{pageNum,pageSize,total,pages,records}}` 形态，字段 camelCase、全部为字符串。
  - 字段较多，下方输出参数表列核心列，完整字段见协议结构 `SwIndustryDailyMetricsItem`。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| level | int | N | 行业层级：1/2/3；不传时按 `industry_code` 自动匹配 |
| start_date | string | Y | 起始日期，YYYYMMDD |
| end_date | string | Y | 截止日期，YYYYMMDD |
| industry_code | string | Y | 行业代码，带 .SI 后缀，如 801010.SI |
| page | int | N | 页码，从 1 开始 |
| page_size | int | N | 每页数量 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项；元素字段见下方 |

## 调用方法（MCP）

> MCP 工具名 `ft_sw_industry_daily_metrics`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

以下调用省略 `level`，由服务按行业代码自动匹配层级：

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_sw_industry_daily_metrics","arguments":{"start_date":"20260520","end_date":"20260616","industry_code":"801010.SI","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "ft_sw_industry_daily_metrics",
                {'start_date': '20260520',
                 'end_date': '20260616',
                 'industry_code': '801010.SI',
                 'page': 1,
                 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
