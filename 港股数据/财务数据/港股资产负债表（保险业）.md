# 港股资产负债表（保险业）（MCP 工具 `ft_hk_balance_insur`）

> **MCP 工具**：`ft_hk_balance_insur`（category: `港股数据/财务数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 为同值 JSON。

- 描述：分页查询保险业港股资产负债表，包含保险合同、再保险资产、应收保费、负债和权益等科目。
- 提示：必须提供港股代码、报告期范围或 `year`+`report_type` 中至少一种过滤条件。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| trade_code | string | N | 港股代码，例如 `01299.HK` 或 `1299` |
| year | integer | N | 报告年份，需与 `report_type` 同时传入；仅支持当前年份及前两年（当前为 2024–2026） |
| report_type | string | N | `annual` 或 `semi`，需与 `year` 同时传入 |
| start_date | integer | N | 报告期下界，`YYYYMMDD` |
| end_date | integer | N | 报告期上界，`YYYYMMDD` |
| page | integer | N | 页码，默认 1 |
| page_size | integer | N | 每页数量，默认 20，最大 500 |

## 输出参数

`data` 为报告期记录数组；分页信息位于 `metadata`。核心字段：

| 字段 | 类型 | 描述 |
|------|------|------|
| trade_code / security_name | string | 港股代码 / 证券名称 |
| end_date / report_type / currency | string | 报告期、报表类型、币种 |
| account_std / company_type | string | 会计准则、公司类型 |
| cash / debt_invest / finaetatfval_tpl | string | 现金、债权投资、按公允价值计量金融资产 |
| insur_contract / reins_assets | string | 保险合同负债、再保险资产 |
| total_assets / tot_liabl | string | 总资产、总负债 |
| share_holderequity / tot_interests | string | 股东权益、总权益 |

响应还包含完整的保险业资产负债科目；金额字段以字符串返回。

## 调用方法（MCP）

> MCP 工具名 `ft_hk_balance_insur`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_hk_balance_insur","arguments":{"trade_code":"01299.HK","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "ft_hk_balance_insur",
                {'trade_code': '01299.HK', 'page': 1, 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
