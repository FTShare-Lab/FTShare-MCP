# 一致行动人明细（MCP 工具 `ft_get_yzxdr_detail`）

> **MCP 工具**：`ft_get_yzxdr_detail`（category: `股票数据/基础数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 为同值 JSON。

- 描述：按年份和季度分页查询一致行动人持股明细，可按六位股票代码进一步过滤。
- 提示：`year`、`quarter` 必填，季度范围为 1–4；`page_size` 最大 200。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| year | integer | Y | 报告年份 |
| quarter | integer | Y | 季度，1–4 |
| stock_code | string | N | 六位股票代码 |
| page | integer | N | 页码，默认 1 |
| page_size | integer | N | 每页数量，默认 50，最大 200 |

## 输出参数

`data` 为一致行动人记录数组；分页信息位于 `metadata`。核心字段：

| 字段 | 类型 | 描述 |
|------|------|------|
| stock_code / stock_name | string | 股票代码 / 名称 |
| data_date / notice_date | string | 数据日期 / 公告日期 |
| holder_name / holder_type / holder_rank | string | 股东名称、类型和排名 |
| hold_shares / hold_ratio / hold_value | string | 持股数量、比例和市值 |
| group_shares / group_ratio | string | 一致行动组合持股数量和比例 |
| tradable_shares / share_type | string | 可流通股数 / 股份类型 |
| ratio_change / shares_change | string/null | 比例变化 / 股数变化 |
| is_controlling | string | 是否控股 |

## 调用方法（MCP）

> MCP 工具名 `ft_get_yzxdr_detail`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_get_yzxdr_detail","arguments":{"year":2026,"quarter":1,"stock_code":"000001","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "ft_get_yzxdr_detail",
                {'year': 2026, 'quarter': 1, 'stock_code': '000001', 'page': 1, 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
