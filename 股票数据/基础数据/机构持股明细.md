# 机构持股明细（MCP 工具 `ft_get_stock_institution_holdings_detail`）

> **MCP 工具**：`ft_get_stock_institution_holdings_detail`（category: `股票数据/基础数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询单只 A 股在指定报告期的机构持仓明细，包括机构名称、持股数量、持股市值、净值比例、流通比例和总股本比例等。`stock_code`、`report_type`、`inst_type`、`year` 均必填。
- 数据范围：按报告期查询
- 单次限量：默认 `page=1`、`page_size=20`
- 提示：
  - `report_type` 取值：q1 / q2 / q3 / annual / announcement。
  - `inst_type` 取值：all_inst（返回全部）/ fund / qfii / insurance / social_security / securities / trust / other，非 all_inst 时按机构类型过滤。
  - 缺少必填参数时返回错误。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| stock_code | string | Y | 股票代码 |
| year | int | Y | 年份 |
| report_type | ReportType | Y | 报告类型：q1 / q2 / q3 / annual / announcement |
| inst_type | InstitutionType | Y | 机构类型：all_inst / fund / qfii / insurance / social_security / securities / trust / other |
| page | int | N | 页码，默认 1 |
| page_size | int | N | 每页条数，默认 20 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| circ | decimal | Y | 流通比例 |
| end_date | int | Y | 报告期截止日 YYYYMMDD |
| hld_shares | decimal | Y | 持股数量 |
| inst_id | string | Y | 机构 ID |
| inst_main_id | string | Y | 机构主编码 |
| inst_name | string | Y | 机构名称 |
| inst_type | string | Y | 机构类型 |
| mkt_value | decimal | Y | 市值 |
| nv_ratio | decimal | Y | 净值比例 |
| report_type | string | Y | 报告类型 |
| stock_code | string | Y | 股票代码 |
| stock_name | string | Y | 股票名称 |
| total_share_ratio | decimal | Y | 总股本比例 |
| year | int | Y | 年份 |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_get_stock_institution_holdings_detail","arguments":{"stock_code":"000001.SZ","year":2025,"report_type":"annual","inst_type":"all_inst","page":1,"page_size":5}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_get_stock_institution_holdings_detail',
                {'stock_code': '000001.SZ', 'year': 2025, 'report_type': 'annual', 'inst_type': 'all_inst', 'page': 1, 'page_size': 5},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
