# 信号最新快照（MCP 工具 `ft_stock_signal_latest_snapshot`）

> **MCP 工具**：`ft_stock_signal_latest_snapshot`（category: `股票数据/特色数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 为同值 JSON。

- 描述：分页查询股票创新高/新低、连续涨跌、均线突破和量价类信号的最新命中记录。
- 提示：`signal_type` 可选；`page` 和 `page_size` 均可省略，默认 1/50；`page_size` 最大 200。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| signal_type | string | N | 信号类型；不传返回全部支持类型 |
| page | integer | N | 页码，从 1 开始，默认 1 |
| page_size | integer | N | 每页数量，默认 50，范围 1–200 |

支持的 `signal_type`：`new_high_month`、`new_high_60d`、`new_high_120d`、`new_high_250d`、`new_low_month`、`new_low_60d`、`new_low_120d`、`new_low_250d`、`consecutive_up`、`consecutive_down`、`consecutive_vol_up`、`consecutive_vol_down`、`break_up_ma5`、`break_up_ma10`、`break_up_ma20`、`break_down_ma5`、`break_down_ma10`、`break_down_ma20`、`vol_price_rise`、`vol_price_fall`。

## 输出参数

`data` 为信号记录数组；分页信息位于 `metadata`。

| 字段 | 类型 | 描述 |
|------|------|------|
| symbol | string | 带交易所后缀的标的代码 |
| code | string | 六位股票代码 |
| latest_trade_date | string | 最新命中日期，`YYYY-MM-DD` |
| signal_type | string | 信号类型编码 |
| signal_name | string | 信号名称 |
| signal_detail | string | 信号说明 |
| close_price | string | 最新收盘价 |
| volume | string | 最新成交量 |

## 调用方法（MCP）

> MCP 工具名 `ft_stock_signal_latest_snapshot`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

以下调用特意省略 `page` 和 `page_size`，用于验证服务端默认值：

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_stock_signal_latest_snapshot","arguments":{"signal_type":"new_high_60d"}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_stock_signal_latest_snapshot',
                {'signal_type': 'new_high_60d'},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
