# 雪球股票排名（MCP 工具 `ft_xueqiu_rank`）

> **MCP 工具**：`ft_xueqiu_rank`（category: `股票数据/特色数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询雪球股票排行榜最新一期快照。支持按榜单组（关注 / 讨论 / 交易）与周期（本周新增 / 最热门）组合查询；返回榜单展示名、核心指标名（关注度/讨论数/交易数）、总记录数与排行条目（排名、统一代码、简称、核心指标值、最新价、雪球原始代码）。提示：`trade_date` 不传默认取最新一期；格式 `YYYY-MM-DD`。
- 数据范围：雪球排名最新一期快照（无时间序列）
- 单次限量：分页返回，默认 `page=1`、`page_size=20`，上限 100
- 提示：
  - 三层命名遵循 CLAUDE.md 来源标识约定：v0 `/stock-rank/xueqiu`、client `xueqiu_stock_rank`、v1 `/xueqiu-rank`、对外类型 `XueqiuRank*`。
  - `trade_date` 不传默认取最新一期；格式 `YYYY-MM-DD`。
  - 响应为 `ApiResponse<XueqiuRankResponseData>` 信封结构。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| rank_group | string | N | 榜单组：`follow`（关注）/ `tweet`（讨论）/ `deal`（交易） |
| period | string | N | 周期：`7d`（本周新增）/ `total`（最热门） |
| trade_date | string | N | 交易日期，格式 `YYYY-MM-DD`，不传默认取最新 |
| page | int | N | 页码，从 1 开始，默认 1 |
| page_size | int | N | 每页条数，默认 20，最大 100 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项；元素字段见下方 |

### data 业务字段

XueqiuRankItem：

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| rank_no | int | Y | 排名 |
| normalized_symbol | string | Y | 统一股票代码，如 `000001` |
| stock_name | string | Y | 股票简称 |
| metric_value | string | Y | 核心指标值（关注度/讨论数/交易数） |
| latest_price | string | Y | 最新价 |
| raw_symbol | string | Y | 雪球原始代码，如 `SZ000001` |

## 调用方法（MCP）

> MCP 工具名 `ft_xueqiu_rank`。MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_xueqiu_rank","arguments":{}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_xueqiu_rank',
                {},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
