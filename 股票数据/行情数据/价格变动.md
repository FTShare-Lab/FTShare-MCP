# 价格变动（MCP 工具 `ft_get_price_change`）

> **MCP 工具**：`ft_get_price_change`（category: `股票数据/行情数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：计算单只股票 N 个交易日的区间涨跌幅。给定 `stock_code`、基准日 `base_date`、交易日数量 `n` 与方向 `direction` 后自动排除非交易日；`forward` 表示以基准日为结束日向前取 N 个交易日，`backward` 表示以基准日为起始日向后取 N 个交易日。结果包括起止交易日、复权后的起止收盘价、价格变动额和涨跌幅，建议 `n` 不超过 365。
- 数据范围：按交易日计算（依赖交易日历与复权日线，覆盖标的上市以来交易日）
- 单次限量：单次一个标的、一个区间
- 提示：
  - `stock_code` 为 6 位纯数字代码（兼容沪/深/创业板/科创板）。
  - `direction` 仅接受 `forward` / `backward`。
  - 起止价格已按复权类型处理，保留 2 位小数。
  - 建议查询区间 `n` 不超过 365 个交易日。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| stock_code | string | Y | 目标股票 6 位纯数字代码，兼容沪市/深市/创业板/科创板 |
| base_date | string | Y | 涨跌幅计算基准日，格式 YYYYMMDD |
| n | uint32 | Y | 需计算的有效交易日数量，建议不超过 365 |
| direction | string | Y | 计算方向：forward（基准日为结束日）/ backward（基准日为开始日） |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| actual_trading_days | uint32 | Y | 实际参与计算的有效交易日数量 |
| base_date | string | Y | 基准日期（YYYY-MM-DD） |
| change_pct | decimal | Y | N 日涨跌幅百分比 = price_change/start_price×100，保留 2 位小数 |
| direction | string | Y | 计算方向（forward/backward） |
| end_date | string | Y | 涨跌幅区间结束交易日（YYYY-MM-DD，已过滤非交易日） |
| end_price | decimal | Y | 结束交易日收盘价（复权后，保留 2 位小数） |
| n | uint32 | Y | 计算的有效交易日数量 |
| price_change | decimal | Y | 价格变动额 = end_price - start_price，保留 2 位小数 |
| start_date | string | Y | 涨跌幅区间起始交易日（YYYY-MM-DD，已过滤非交易日） |
| start_price | decimal | Y | 起始交易日收盘价（复权后，保留 2 位小数） |
| stock_code | string | Y | 目标股票 6 位纯代码 |
| stock_name | string | Y | 股票中文简称 |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_get_price_change","arguments":{"stock_code":"600519","base_date":"20260624","n":5,"direction":"backward"}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_get_price_change',
                {'stock_code': '600519', 'base_date': '20260624', 'n': 5, 'direction': 'backward'},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
