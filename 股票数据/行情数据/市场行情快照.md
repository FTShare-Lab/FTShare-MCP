# 市场行情快照（MCP 工具 `ft_daec_market_snapshot`）

> **MCP 工具**：`ft_daec_market_snapshot`（category: `股票数据/行情数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。

- 描述：查询全市场或单个交易所的行情快照，返回市场状态、涨跌幅、成交量额，以及按涨跌幅区间统计的涨跌分布（9 档）。返回单对象（非分页）。
- 数据范围：最新实时快照
- 单次限量：单次返回一个快照对象，无分页
- 提示：
  - `scope` 可选，默认 `ChinaStock`（全市场）；可指定 `Xshg`（沪市）/ `Xshe`（深市）/ `Bjse`（北交所）。
  - 市场状态依据北京时间交易时段判断，非交易时段 `status` 为 `closed`。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| scope | string | N | 市场范围：`ChinaStock`（默认）/ `Xshg` / `Xshe` / `Bjse` |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；本工具返回单对象，`data` 为长度 1 的数组。

对象字段：

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| status | string | Y | 市场状态（如 `closed` / 交易中） |
| change_rate | float64 | Y | 涨跌幅 |
| volume | int64 | Y | 成交量，单位股 |
| turnover | string | Y | 成交额，单位元 |
| prev_turnover | string | N | 前成交额，单位元 |
| distribution | object | Y | 涨跌分布（9 档，见下） |

distribution（各档股票数量）：

| 名称 | 类型 | 描述 |
|------|------|------|
| up_limited | int32 | 涨停 |
| up_5pct_to_limited | int32 | 涨 5% ~ 涨停 |
| up_1pct_to_5pct | int32 | 涨 1% ~ 5% |
| up_0pct_to_1pct | int32 | 涨 0 ~ 1% |
| flat | int32 | 平盘 |
| down_0pct_to_1pct | int32 | 跌 0 ~ 1% |
| down_1pct_to_5pct | int32 | 跌 1% ~ 5% |
| down_5pct_to_limited | int32 | 跌 5% ~ 跌停 |
| down_limited | int32 | 跌停 |

## 调用方法（MCP）

> MCP 工具名 `ft_daec_market_snapshot`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_daec_market_snapshot","arguments":{"scope":"ChinaStock"}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_daec_market_snapshot',
                {'scope': 'ChinaStock'},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```

- `status` 依据北京时间交易时段判断，非交易时段为 `closed`。
- `distribution` 各档为快照时刻的股票数量统计，9 档合计覆盖全市场标的。
