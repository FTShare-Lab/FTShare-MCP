# 标的分时数据（MCP 工具 `ft_daec_prices`）

> **MCP 工具**：`ft_daec_prices`（category: `股票数据/行情数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询指定标的的 1 分钟分时数据（价格、均价、成交量、成交额）。支持按预置区间（`range`）、近 N 个交易日（`days`）或毫秒时间戳起点（`ts_ms`）取数，三个时间参数互斥，优先级 `ts_ms` > `days` > `range`，都不传默认最近 5 个交易日。返回数组（非分页）。
- 数据范围：1 分钟粒度分时，覆盖近若干交易日
- 单次限量：按时间参数返回区间内全部分时点，无分页
- 提示：
  - `symbol` 必填，格式 `代码.市场`（如 `600000.XSHG`），兼容短后缀（如 `600000.SH`）。
  - 三个时间参数 `range` / `days` / `ts_ms` 互斥，同时传多个时按优先级取一个。
  - `days` 最大 30。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| symbol | string | Y | 标的代码，如 `600000.XSHG` / `600000.SH` |
| range | string | N | 预置时间区间：`Today`（当日）/ `FiveDays`（近 5 日，默认）；优先级低于 `days` 与 `ts_ms` |
| days | integer | N | 近 N 个交易日至今，最大 30；优先级高于 `range`，低于 `ts_ms` |
| ts_ms | integer | N | 起始毫秒时间戳，最小 0；优先级最高 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。

数组，每个分时点：

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| ts_ms | int64 | Y | 时间戳，单位毫秒 |
| price | float64 | Y | 成交价格，单位元 |
| avg_price | float64 | N | 均价，单位元 |
| volume | int64 | Y | 成交量，单位股 |
| turnover | float64 | Y | 成交额，单位元 |

## 调用方法（MCP）

> MCP 工具名 `ft_daec_prices`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_daec_prices","arguments":{"symbol":"600000.XSHG","range":"Today"}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "ft_daec_prices",
                {'symbol': '600000.XSHG', 'range': 'Today'},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```

## 注意事项

- 仅返回交易日盘中数据，非交易时段无数据。
- 三个时间参数互斥，优先级 `ts_ms` > `days` > `range`，同时传递时仅生效一个。
- 时间戳为毫秒级，换算秒级时间需除以 1000。
