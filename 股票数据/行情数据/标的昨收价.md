# 标的昨收价（MCP 工具 `ft_daec_prev_closes`）

> **MCP 工具**：`ft_daec_prev_closes`（category: `股票数据/行情数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。

- 描述：查询指定标的在一段日期区间内每个交易日的昨收价（前收盘价）。常用于计算复权因子、验证涨跌停价等场景。返回数组（非分页）。
- 数据范围：按交易日
- 单次限量：由 `since` / `until` 区间决定，无分页
- 提示：
  - `symbol` / `since` / `until` 均必填，日期格式 `YYYYMMDD`（8 位数字）。
  - 仅返回交易日数据，非交易日无数据。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| symbol | string | Y | 标的代码，如 `600000.XSHG` |
| since | string | Y | 起始日期 `YYYYMMDD`，如 `20240501`（需匹配 `^[0-9]{8}$`） |
| until | string | Y | 结束日期 `YYYYMMDD`，如 `20240531`（需匹配 `^[0-9]{8}$`） |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`。

数组，每个交易日一条：

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| date | string | Y | 日期，格式 `YYYY-MM-DD` |
| prev_close | string | Y | 昨收价，单位元 |

## 调用方法（MCP）

> MCP 工具名 `ft_daec_prev_closes`。MCP Streamable HTTP 要求先 `initialize` 获取 `Mcp-Session-Id`，再发送 `notifications/initialized`，最后调用 `tools/call`。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  # MCP 业务与协议错误仍可能使用 HTTP 200，必须检查 JSON-RPC 响应。
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_daec_prev_closes","arguments":{"symbol":"600000.XSHG","since":"20240501","until":"20240510"}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                "ft_daec_prev_closes",
                {'symbol': '600000.XSHG', 'since': '20240501', 'until': '20240510'},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```

## 注意事项

- 仅返回交易日数据，非交易日无数据。
- 价格字段为字符串类型，避免浮点精度丢失。
- 可用于复权因子计算、涨跌停价校验等下游场景。
