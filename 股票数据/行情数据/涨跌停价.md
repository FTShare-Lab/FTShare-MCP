# 涨跌停价（MCP 工具 `ft_stk_limit`）

> **MCP 工具**：`ft_stk_limit`（category: `股票数据/行情数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询股票、ETF 和可转债每日的昨收价、涨停价与跌停价，不包含指数。支持按 `trade_date` 查询单日全市场并以 `instrument_type` 筛选证券类型，也支持按 `symbol`（或 `symbol_id` 与 `market_id`）及 `start_date`、`end_date` 查询单个标的的历史区间。
- 数据范围：按交易日（单日全市场快照或单票历史区间）
- 单次限量：分页返回，默认 `page=1`、`page_size=50`、最大 500
- 提示：
  - `instrument_type` 取值 `stock` / `etf` / `cb`；不传返回三类（排除指数）。
  - `symbol` 支持 `000001.SZ` / `000001.XSHE` / `600519.SH` 等格式；存在 `symbol` 时忽略 `symbol_id`+`market_id`。
  - 区间查询（`start_date`/`end_date`）需配合 `symbol` 或 `symbol_id`+`market_id`。
  - `page` 默认 1，`page_size` 默认 50、最大 500。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| instrument_type | string | N | 标的类型：stock / etf / cb；不传返回三类（排除指数） |
| symbol | string | N | 标的代码，支持 000001.SZ / 000001.XSHE / 600519.SH 等；存在时忽略 symbol_id+market_id |
| symbol_id | int32 | N | 标的 ID，与 market_id 配合使用 |
| market_id | int16 | N | 市场 ID，与 symbol_id 配合使用 |
| trade_date | int32 | N | 交易日 YYYYMMDD，查单日全市场时使用 |
| start_date | int32 | N | 单票历史区间起始日 YYYYMMDD（需配 symbol 或 symbol_id+market_id） |
| end_date | int32 | N | 单票历史区间结束日 YYYYMMDD |
| page | uint32 | N | 页码，默认 1 |
| page_size | uint32 | N | 每页条数，默认 50，最大 500 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| down_limit | decimal | N | 跌停价 |
| instrument_type | string | Y | 标的类型：stock / etf / cb |
| pre_close | decimal | N | 昨收价 |
| trade_date | int32 | Y | 交易日（YYYYMMDD） |
| ts_code | string | Y | 标的代码（如 000001.SZ） |
| up_limit | decimal | N | 涨停价 |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_stk_limit","arguments":{"trade_date":20260624,"page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_stk_limit',
                {'trade_date': 20260624, 'page': 1, 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
