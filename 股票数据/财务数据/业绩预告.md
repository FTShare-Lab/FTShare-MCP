# 业绩预告（MCP 工具 `ft_performance_forecasts_paginated`）

> **MCP 工具**：`ft_performance_forecasts_paginated`（category: `股票数据/财务数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：查询 A 股上市公司业绩预告，包括预增、预减、略增、略减、续亏、扭亏、续盈等预告类型，以及预测值上下限、同比变化上下限和去年同期值。支持按 `stock_code` 查询单只股票全部报告期，或按 `year` 和 `report_type` 查询全市场指定报告期；`report_type` 支持 `q1`、`q2`、`q3` 和 `annual`。
- 数据范围：按报告期查询
- 单次限量：模式B 分页默认 `page=1`、`page_size=50`，最大 500；模式A 单票查询不分页，返回该票全部记录（`total_pages=1`）
- 提示：
  - `stock_code` 格式为 6 位数字 + 交易所后缀（如 `000001.SZ`），模式A 与模式B 二选一。
  - 模式A 单票查询不分页，返回该票全部报告期；模式B 才按 `page/page_size` 分页。
  - 预告为预测值区间，`forecast_value_min` / `forecast_value_max` 必成对出现；同比百分比同理。
  - `forecast_subject`（预测科目）区分净利润 / 营业收入等不同预告口径。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| stock_code | string | N | A 股代码，6 位数字 + 后缀（如 000001.SZ）；存在则进入模式A 单票查询 |
| year | int | N | 年份（模式B 必填），如 2024 |
| report_type | string | N | 报告期类型（模式B 必填）：q1 / q2 / q3 / annual |
| page | int | N | 页码（模式B 必填），从 1 开始，默认 1 |
| page_size | int | N | 每页条数（模式B 必填），默认 50，最大 500 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| forecast_subject | string | Y | 预测科目（如 净利润 / 营业收入） |
| forecast_type | string | Y | 预告类型：预增 / 预减 / 略增 / 略减 / 续亏 / 扭亏 / 续盈 等 |
| forecast_value_max | decimal | Y | 预测值上限 |
| forecast_value_min | decimal | Y | 预测值下限 |
| last_year_value | decimal | Y | 去年同期值 |
| publish_date | string | Y | 发布日期 YYYY-MM-DD |
| report_type | string | Y | 报告期类型：q1 / q2 / q3 / annual |
| report_type_cn | string | Y | 报告期中文名 |
| stock_code | string | Y | A 股代码 |
| stock_name | string | Y | 股票名称 |
| unit | string | Y | 单位（如 元） |
| year | int | Y | 年份 |
| yoy_change_max | decimal | Y | 同比变化上限（%） |
| yoy_change_min | decimal | Y | 同比变化下限（%） |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_performance_forecasts_paginated","arguments":{"year":2025,"report_type":"annual","page":1,"page_size":2}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_performance_forecasts_paginated',
                {'year': 2025, 'report_type': 'annual', 'page': 1, 'page_size': 2},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
