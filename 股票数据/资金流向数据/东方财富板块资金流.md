# 东方财富板块资金流（MCP 工具 `ft_get_eastmoney_sector_flow`）

> **MCP 工具**：`ft_get_eastmoney_sector_flow`（category: `股票数据/资金流向数据`）。返回统一 MCP 输出：`structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是同值的序列化 JSON，不额外返回 Markdown。输入参数 / 输出参数 / 数据样例见下文。
> 文中 `Response`、`items`、`records`、`code`、`message` 等名称仅为字段说明；MCP 对外固定为上述 `metadata/data`。

- 描述：获取东方财富行业、概念和地域板块日资金流数据，包括主力、超大单、大单、中单和小单净流入及净占比。支持按板块代码、板块类型、交易日或日期区间筛选。数据来源：东方财富。
- 数据范围：资金流类，最新一期或当日快照
- 单次限量：分页返回，默认 `page=1`、`page_size=50`、最大 `page_size=200`
- 提示：
  - `sector_type` 取值：industry（行业）/ concept（概念）/ regional（地域）。
  - `sector_code` 为东财板块代码，以 BK 开头（如 BK0488）。
  - `trade_date` 与 `start_date`/`end_date` 互斥。

## 输入参数

| 名称 | 类型 | 必选 | 描述 |
|------|------|------|------|
| sector_code | string | N | 板块代码，如 BK0488 |
| sector_type | string | N | 板块类型：industry / concept / regional |
| trade_date | string | N | 交易日 YYYY-MM-DD；与 start_date/end_date 互斥 |
| start_date | string | N | 区间起始日 YYYY-MM-DD；需与 end_date 同时提供 |
| end_date | string | N | 区间结束日 YYYY-MM-DD；需与 start_date 同时提供 |
| page | int | N | 页码，从 1 开始，默认 1 |
| page_size | int | N | 每页条数，默认 50，最大 200 |

## 输出参数

> MCP 固定输出信封为 `structuredContent.metadata` + `structuredContent.data`；`content[0].text` 是与其同值的序列化 JSON，不是 Markdown。
>
> `items` / `records` / `code` / `message` 等传输字段不会直接出现在 MCP 结果中；分页与截断信息统一归入 `metadata`。

| MCP 字段 | 类型 | 必填 | 描述 |
|----------|------|------|------|
| metadata | object | Y | 契约版本、数据来源、工具名、业务口径、总量、分页、返回条数、截断状态及 warnings |
| data | array | Y | 归一化后的业务数据项 |

### data 业务字段

| 名称 | 类型 | 默认显示 | 描述 |
|------|------|---------|------|
| large_net | string | Y | 大单净流入（元） |
| large_pct | string | Y | 大单净占比（%） |
| main_net | string | Y | 主力净流入（元） |
| main_pct | string | Y | 主力净占比（%） |
| medium_net | string | Y | 中单净流入（元） |
| medium_pct | string | Y | 中单净占比（%） |
| sector_code | string | Y | 板块代码，如 BK0488 |
| sector_name | string | Y | 板块名称，如 半导体 |
| sector_type | string | Y | 板块类型：industry / concept / regional |
| small_net | string | Y | 小单净流入（元） |
| small_pct | string | Y | 小单净占比（%） |
| super_large_net | string | Y | 超大单净流入（元） |
| super_large_pct | string | Y | 超大单净占比（%） |
| trade_date | string | Y | 交易日期 YYYY-MM-DD |

## 调用方法（MCP）

> MCP Streamable HTTP 要求**先 initialize 拿 `Mcp-Session-Id`，发送 `notifications/initialized`，再 `tools/call`**，后续请求同时带该 Session ID 和协商后的 `MCP-Protocol-Version`。返回统一 `metadata/data` 结构化输出；`content[0].text` 为同值 JSON 文本，不额外返回 Markdown。

**curl**：

```bash
set -euo pipefail

MCP_BASE_URL="<MCP_BASE_URL>"

check_mcp_response() {
  local response=$1
  printf '%s\n' "$response"
  if printf '%s\n' "$response" | grep -Eq '"isError"[[:space:]]*:[[:space:]]*true|"error"[[:space:]]*:[[:space:]]*\{'; then
    return 1
  fi
}

SID=$(curl -fsS -m 60 -D - -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-11-25","capabilities":{},"clientInfo":{"name":"ftshare-doc-example","version":"1.0.0"}}}' \
  | awk 'tolower($1)=="mcp-session-id:" {print $2}' \
  | tr -d '\r')

if [ -z "$SID" ]; then
  printf '%s\n' 'initialize 未返回 Mcp-Session-Id' >&2
  exit 1
fi

curl -fsS -m 60 -o /dev/null -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","method":"notifications/initialized"}'

CALL_RESPONSE=$(curl -fsS -m 60 -X POST "$MCP_BASE_URL" \
  -H "Accept: application/json, text/event-stream" \
  -H "Content-Type: application/json" \
  -H "Mcp-Session-Id: $SID" \
  -H "MCP-Protocol-Version: 2025-11-25" \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"ft_get_eastmoney_sector_flow","arguments":{"sector_type":"industry","page":1,"page_size":5}}}')

check_mcp_response "$CALL_RESPONSE"
```

**Python（`mcp` SDK，自动握手管理 session）**：

```python
import asyncio

from mcp import ClientSession
from mcp.client.streamable_http import streamable_http_client


MCP_BASE_URL = "<MCP_BASE_URL>"


async def main():
    async with streamable_http_client(MCP_BASE_URL) as (read_stream, write_stream):
        async with ClientSession(read_stream, write_stream) as session:
            await session.initialize()
            result = await session.call_tool(
                'ft_get_eastmoney_sector_flow',
                {'sector_type': 'industry', 'page': 1, 'page_size': 5},
            )
            if result.is_error:
                raise RuntimeError(result.content[0].text)
            print(result.structured_content)
            print(result.content[0].text)


asyncio.run(main())
```
